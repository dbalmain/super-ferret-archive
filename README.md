# super-ferret-archive

Companion of [github.com/dbalmain/super-ferret](https://github.com/dbalmain/super-ferret).

It holds the closed documents and raw results that were moved out of the main
repository so that searching `docs/` there stays cheap:

- `docs/research/`: the 2026-09 survey, measured baseline and item-13 kit.
- `docs/S1B.md`, `S1PLUS.md`, `S2.md`, `S3.md`: closed milestone designs.
- `docs/D65C.md`, `SPARSE.md`, `SCREENS.md`, `FMINDEX.md`, `SCAN.md`,
  `TOKENS.md`: closed experiment records.
- `docs/measurements/*/results.json`: raw result files.

Paths match the main repository's, so `docs/S2.md` there is `docs/S2.md` here.
Links inside these pages to living documents (DESIGN, ROADMAP, DECISIONS, FIND,
GREP and so on) point at files that live only in the main repository.

Home-directory prefixes in the historical text were rewritten from
`/home/dave` to `~`; nothing else was edited.
